# 青い炎のテーマ

目的: 体育祭のバナーの黒地、白文字、濃紺から青緑へ変わる細長い炎を、ダッシュボードの下端で静かに揺らす。

既存の `dash` と並ぶ `blue-flame` を追加する。配色は daisyUI、描画とライフサイクルは専用のクライアントコンポーネントに分離する。設定・保存は既存の color-mode を使う。初期テーマは変更しない。

## 表現方法

CSS/SVG は軽いが複雑な輪郭変形の調整に制約がある。WebGL は高品質な流体表現に適するが、この装飾には複雑さが増す。実装判断として Canvas 2D の曲線とグラデーションを採用する。HTML-in-Canvas は UI のテクスチャ化が必要な場合の API であり、今回は使わない。

炎は画面下部約 32% に限定し、背景だけで描画する。文字と操作は通常の DOM。黒い隙間、濃紺の長い先端、青緑の根元を重ねる。バナーの文字や日付そのものは転載しない。

動きを減らす設定では静止画、非表示タブと非表示レイアウトでは停止、テーマ解除では observer・イベント・RAF を破棄。解像度とフレームレートを制限する。Canvas が使えない場合も黒背景と控えめな青いグラデーションが残る。
