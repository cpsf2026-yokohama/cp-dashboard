# 予約動画の先行読み込みとイベント当日表示

更新日: 2026-10-19

## 予約動画

- 公開の `GET /api/schedule` は、接続中の画面が動画を先に準備できるよう、現在時刻の60秒前から5分後までの予約を返す。
- 時計画面は10秒ごとに予定を取得し、重複予定を除いて開始時刻順に管理する。
- 次の予定が見つかると、画面外に同じ動画要素を作り `preload="auto"` で事前読み込みする。開始時刻になったらこの要素をそのまま表示・再生する。
- 再生APIが認証不要であること、動画データを保存する動作がないことは従来どおり。
- `preload="auto"` はブラウザーへの読み込み指示であり、通信状況や端末によって開始時刻までに動画全体が読み込まれる保証はない。再生可能な部分を先にバッファーすることで開始待ちを減らす。

## イベント当日

- カウントダウンが0日で、予定日時まで残り時間がある間は「本日開催！」を表示する。
- 残り日数リングに控えめな発光演出、告知テキストと星印に出現・点滅演出を付ける。
- OSで視差効果を減らす設定が有効な場合はアニメーションを止める。
