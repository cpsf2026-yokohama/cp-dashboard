# 予約動画の先行読み込みとイベント当日表示

更新日: 2026-10-19

## 予約動画

- 公開の `GET /api/schedule` は、接続中の画面が動画を先に準備できるよう、現在時刻の60秒前から5分後までの予約を返す。
- 時計画面は10秒ごとに予定を取得し、重複予定を除いて開始時刻順に管理する。
- 次の予定が見つかると、動画全体をCache Storageへダウンロードし、端末内に保持する動画は1本に制限する。再生用のBlob URLも次の1本だけ作り、使用後に解放する。
- ダウンロード完了後はローカルBlob URLを使い、非表示の動画要素で再生可能な状態まで準備する。
- 開始時刻に準備が完了していない場合はダッシュボードを表示したまま「予約動画を準備しています」と知らせる。読み込み完了後に再生画面へ切り替える。
- ブラウザー保存領域が使えない・容量不足・ダウンロード失敗の場合は直接配信に切り替え、5秒分程度のバッファーができてから再生する。
- 再生中にデータ待ちが発生した場合は、黒画面ではなく読み込み表示を重ねる。
- 動画は最大100 MiBまでキャッシュする。これは動画アップロードAPIの現行上限に合わせている。

## イベント当日

- カウントダウンが0日で、予定日時まで残り時間がある間は「本日開催！」を表示する。
- 残り日数リングに控えめな発光演出、告知テキストと星印に出現・点滅演出を付ける。
- OSで視差効果を減らす設定が有効な場合はアニメーションを止める。
