# 管理画面の入力フォーカス修正レポート

## 状態

修正済み。ローカルの管理画面で入力中のフォーカス維持を確認しました。本番環境へのデプロイは行っていません。

## 症状と原因

管理画面の「端末への反映」で、チャイム時刻とカウントダウン予定の各行に、編集中の値を含む Vue の `key` が付いていました。値を一文字編集するたびに `key` が変わり、Vue が行を別要素として作り直していたため、入力欄がフォーカスを失っていました。

## 修正

`pages/admin.vue` のチャイム時刻行と予定行の `key` を、編集で変化しない配列インデックスに変更しました。これにより通常の入力では行が再生成されず、フォーカスが保たれます。

## 動作確認

- ローカルの `/admin` を開き、「端末への反映」タブを表示。
- 「毎年繰り返す予定の日付 1」を `04-17` に編集。
- 編集後も同じ日付入力が `document.activeElement` であり、アクセシビリティツリー上でも `[active]` と値 `04-17` を確認。
- 確認用に変更した値はページ再読み込みで破棄し、サーバーへ保存していません。

## 対象範囲

チャイム時刻・予定行のインライン編集を対象とします。行の追加・削除時には配列インデックスが変わるため、その操作後は一覧が再描画されます。
